# ✈️ AI Travel Planner

A simple website that generates a day-by-day travel itinerary and an estimated budget
from a destination, number of days, travelers, budget and travel style.

## Features
- Destination input (with suggestions)
- Daily itinerary (morning, lunch, afternoon, evening)
- Estimated budget with breakdown, compared to your budget
- Print / save as PDF

## Tech
HTML, CSS, JavaScript (no frameworks, no backend)

## Run locally
Download the files and open `index.html` in any browser.

## Live demo
https://YOUR-USERNAME.github.io/ai-travel-planner/

## How the "AI" works
A built-in knowledge base of destinations (attractions, food, evening plans and average
daily costs) plus rule-based logic builds the plan. A real LLM API can be added later.

## Future improvements
